### Composable patterns

Most structural blocks follow a compound split:

```tsx
<Card>
  <Card.Header title="ATS recommendations" />
  <Card.Body>{/* content */}</Card.Body>
  <Card.Footer>{/* actions */}</Card.Footer>
</Card>

<Modal isOpen={open} onClose={close} title="ATS report" footer={<Button>Close</Button>}>
  {/* content */}
</Modal>
```

Shared utilities (<code>cn</code>, <code>focusRing</code>, semantic tokens) are exported from the package root.
Visual reference for colors and viewports: the <TokensLink /> page.

<SectionHeader kicker="Getting started" title="Quick start" id="quick-start" />

### 1. Install the package

```bash
pnpm add @aquellec/ui lucide-react
# ou : npm install @aquellec/ui lucide-react
```

`react`, `react-dom` and `lucide-react` are **peer dependencies** — install them in your host application.

### 2. Configure Tailwind CSS

Import the design system preset to inherit the <code>brand</code>, <code>ai</code> and <code>semantic.*</code> tokens:

```js
// tailwind.config.js
/** @type {import('tailwindcss').Config} */
module.exports = {
  presets: [require('@aquellec/ui/tailwind-preset').default],
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@aquellec/ui/dist/**/*.{js,mjs}',
  ],
};
```

ESM / TypeScript equivalent:

```ts
// tailwind.config.ts
import type { Config } from 'tailwindcss';
import aquellecPreset from '@aquellec/ui/tailwind-preset';

export default {
  presets: [aquellecPreset],
  content: ['./src/**/*.{js,ts,jsx,tsx}'],
} satisfies Config;
```

### 3. Import the components

```tsx
import { Button, Card, Dropzone, ToastProvider, useToast } from '@aquellec/ui';

export function App() {
  return (
    <ToastProvider>
      <Card className="max-w-md">
        <Card.Header title="Upload a resume" />
        <Card.Body>
          <Dropzone accept=".pdf" maxSizeMB={5} onFileSelect={(file) => console.log(file.name)} />
        </Card.Body>
      </Card>
    </ToastProvider>
  );
}
```

### 4. Develop and document locally

```bash
pnpm install
pnpm dev              # Storybook -> http://localhost:6006
pnpm build            # ESM/CJS build plus types
pnpm test:storybook   # Vitest interaction and a11y tests
pnpm build-storybook  # Static documentation export
```
