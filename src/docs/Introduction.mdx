### Patterns composables

La plupart des blocs structurels suivent un découpage compound&nbsp;:

```tsx
<Card>
  <Card.Header title="Recommandations ATS" />
  <Card.Body>{/* contenu */}</Card.Body>
  <Card.Footer>{/* actions */}</Card.Footer>
</Card>

<Modal isOpen={open} onClose={close} title="Rapport ATS" footer={<Button>Fermer</Button>}>
  {/* contenu */}
</Modal>
```

Les utilitaires partagés (<code>cn</code>, <code>focusRing</code>, tokens sémantiques) sont exportés depuis le package racine.
Référence visuelle des couleurs et viewports&nbsp;: page **[Tokens](./?path=/docs/docs-tokens--docs)**.

## Démarrage rapide

### 1. Installer le package

```bash
pnpm add @aquellec/ui lucide-react
# ou : npm install @aquellec/ui lucide-react
```

`react`, `react-dom` et `lucide-react` sont des **peer dependencies** — installez-les dans votre application hôte.

### 2. Configurer Tailwind CSS

Importez le preset du design system pour hériter des tokens <code>brand</code>, <code>ai</code> et <code>semantic.*</code>&nbsp;:

```js
// tailwind.config.js
/** @type {import('tailwindcss').Config} */
module.exports = {
  presets: [require('@aquellec/ui/tailwind-preset').default],
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@aquellec/ui/dist/**/*.{js,mjs}',
  ],
};
```

Équivalent ESM / TypeScript&nbsp;:

```ts
// tailwind.config.ts
import type { Config } from 'tailwindcss';
import aquellecPreset from '@aquellec/ui/tailwind-preset';

export default {
  presets: [aquellecPreset],
  content: ['./src/**/*.{js,ts,jsx,tsx}'],
} satisfies Config;
```

### 3. Importer les composants

```tsx
import { Button, Card, Dropzone, ToastProvider, useToast } from '@aquellec/ui';

export function App() {
  return (
    <ToastProvider>
      <Card className="max-w-md">
        <Card.Header title="Importer un CV" />
        <Card.Body>
          <Dropzone accept=".pdf" maxSizeMB={5} onFileSelect={(file) => console.log(file.name)} />
        </Card.Body>
      </Card>
    </ToastProvider>
  );
}
```

### 4. Développer & documenter localement

```bash
pnpm install
pnpm dev              # Storybook → http://localhost:6006
pnpm build            # Build ESM/CJS + types
pnpm test:storybook   # Tests d'interaction Vitest
pnpm build-storybook  # Export statique de la doc
```

## Qualité & gouvernance

| Axe | Pratique |
| --- | -------- |
| Accessibilité | Addon `@storybook/addon-a11y` activé sur chaque story |
| Interactions | Tests `play()` Vitest via `@storybook/addon-vitest` |
| Viewports | Mobile 375 · Tablet 768 · Desktop 1280 · Wide 1536 |
| Typage | `strict: true`, déclarations `.d.ts` générées dans `dist/` |

Pour toute évolution de token ou de contraste, mettre à jour `src/lib/design-tokens.ts` et la page **Tokens** afin de garder le preset et la documentation alignés.
