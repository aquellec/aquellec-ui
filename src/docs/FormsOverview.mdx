<h2 className="mt-10 mb-3 text-title font-semibold text-neutral-900 dark:text-neutral-50">When to use, and when not</h2>

<div className="mt-4 grid gap-4 md:grid-cols-2">
  <div className="rounded-card border border-neutral-200 p-4 dark:border-neutral-700">
    <p className="text-label font-semibold text-neutral-900 dark:text-neutral-100">Do</p>
    <ul className="mt-2 space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
      <li>label every field visibly — a placeholder is not a label, it disappears the moment someone types;</li>
      <li>say what went wrong and what to do: “The PDF is a scan with no text layer. Ask for a text version.”;</li>
      <li>use <code>helperText</code> for the rule before the error, not after it;</li>
      <li>keep Dropzone on a native file input, so the keyboard and the file picker work unchanged.</li>
    </ul>
  </div>
  <div className="rounded-card border border-neutral-200 p-4 dark:border-neutral-700">
    <p className="text-label font-semibold text-neutral-900 dark:text-neutral-100">Do not</p>
    <ul className="mt-2 space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
      <li>write errors that blame the person: “Invalid input” tells a recruiter nothing;</li>
      <li>hide the character counter until the limit is hit;</li>
      <li>rely on colour alone for the error state — <code>aria-invalid</code> and the message carry it too;</li>
      <li>accept a resume format the parser cannot read; refuse it at the drop, not after the analysis.</li>
    </ul>
  </div>
</div>

<h2 className="mt-10 mb-3 text-title font-semibold text-neutral-900 dark:text-neutral-50">Anatomy</h2>

<ul className="mt-4 max-w-2xl space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
  <li><strong className="text-neutral-900 dark:text-neutral-100">Label</strong> — bound with <code>htmlFor</code>, always rendered.</li>
  <li><strong className="text-neutral-900 dark:text-neutral-100">Field</strong> — the control itself, its border darkening on hover so the hit area is legible.</li>
  <li><strong className="text-neutral-900 dark:text-neutral-100">Helper or error</strong> — one or the other, wired through <code>aria-describedby</code>; the error takes <code>role="alert"</code>.</li>
</ul>

<h2 className="mt-10 mb-3 text-title font-semibold text-neutral-900 dark:text-neutral-50">Localisation</h2>

<p className="mt-4 max-w-2xl text-body text-neutral-600 dark:text-neutral-300">
  Dropzone hard-codes no copy: every string arrives through <code>labels</code>, and the
  French defaults are exported as <code>defaultDropzoneLabels</code> to start a translation
  from. The same holds for DataTable. A design system for hiring is used in the language
  of the team using it.
</p>
