## Typographie

Échelle basée sur les utilitaires Tailwind `text-*` et `font-*`. Police système par défaut (`font-sans`).

<Typeset
  fontSizes={[
    '0.75rem',

  fontWeight={400}
  sampleText="Optimisez votre CV pour les ATS"
  fontFamily="Inter, system-ui, sans-serif"
/>

| Token Tailwind | Taille | Usage typique |
| -------------- | ------ | ------------- |
| `text-xs` | 12px | Labels, badges, métadonnées |
| `text-sm` | 14px | Corps de texte, tableaux, formulaires |
| `text-base` | 16px | Titres de modale, contenu principal |
| `text-lg` | 18px | Titres de section |
| `text-xl` | 20px | En-têtes de page template |
| `text-2xl` | 24px | KPI dashboard |
| `text-3xl` | 30px | Hero pricing |

## Focus & accessibilité

Les anneaux de focus sont centralisés dans `src/lib/focus-ring.ts` :

- `focusRing` — contrôles interactifs standard
- `focusRingDanger` — actions destructives
- `focusRingGhost` — boutons discrets (fermeture modale, icônes)
