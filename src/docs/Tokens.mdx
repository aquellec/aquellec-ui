### Forcer un viewport sur une story

```tsx
export const OnMobile: Story = {
  render: () => <MyPage />,
  globals: {
    viewport: { value: 'mobile', isRotated: false },
  },
};
```

Quand un viewport est défini via `globals`, il est appliqué automatiquement et ne peut plus être changé
depuis la toolbar — utile pour figer un cas de test.

**Raccourcis clavier**&nbsp;: viewport suivant `Alt + V` · précédent `Alt + Shift + V` · réinitialiser `Alt + Ctrl + V`.

### Via le preset Tailwind

Les tokens arrivent dans une application hôte par le preset — aucune feuille de style à importer&nbsp;:

```ts
// tailwind.config.ts
import aquellecPreset from '@aquellec/ui/tailwind-preset';

export default {
  presets: [aquellecPreset],
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@aquellec/ui/dist/**/*.{js,mjs}',
  ],
};
```

Le preset embarque aussi la neutralisation des animations sous `prefers-reduced-motion`.

### En dehors de Tailwind

Les objets bruts restent accessibles pour les usages hors classes utilitaires (graphiques, e-mails, canvas)&nbsp;:

```ts
import { aquellecColors, aquellecThemeExtensions } from '@aquellec/ui';

aquellecColors.brand[600];              // '#0052cc'
aquellecThemeExtensions.boxShadow.card; // ombre des surfaces Card
```

Toute évolution passe par `src/lib/design-tokens.ts`&nbsp;: le preset, les composants et cette page
en découlent automatiquement.
