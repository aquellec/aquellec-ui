Consumed by `Badge`, `Toast`, `Dropzone` and `Input` through the helpers in `src/lib/semantic-colors.ts`,
never as raw colors. Every family exposes four roles: `fg` (text and icon),
`bg` (chip background), `border` and `surface` (banner background).

`bg` and `surface` currently share the same value across all four families: the distinction exists
so they can be split later without touching the components.

### Pinning a viewport on a story

```tsx
export const OnMobile: Story = {
  render: () => <MyPage />,
  globals: {
    viewport: { value: 'mobile', isRotated: false },
  },
};
```

When a viewport is set through `globals` it is applied automatically and can no longer be changed
from the toolbar — useful to pin a test case.

**Keyboard shortcuts**: next viewport `Alt + V` · previous `Alt + Shift + V` · reset `Alt + Ctrl + V`.

### Through the Tailwind preset

Tokens reach a host application through the preset — there is no stylesheet to import:

```ts
// tailwind.config.ts
import aquellecPreset from '@aquellec/ui/tailwind-preset';

export default {
  presets: [aquellecPreset],
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@aquellec/ui/dist/**/*.{js,mjs}',
  ],
};
```

The preset also carries the `prefers-reduced-motion` animation reset.

### Outside Tailwind

The raw objects stay available for uses outside utility classes (charts, emails, canvas):

```ts
import { aquellecColors, aquellecThemeExtensions } from '@aquellec/ui';

aquellecColors.brand[600];              // '#0052cc'
aquellecThemeExtensions.boxShadow.card; // Card surface shadow
```

Every change goes through `src/lib/design-tokens.ts`: the preset, the components and this page all
derive from it automatically.
