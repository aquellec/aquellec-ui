<h2 className="mt-10 mb-3 text-title font-semibold text-neutral-900 dark:text-neutral-50">When to use, and when not</h2>

<div className="mt-4 grid gap-4 md:grid-cols-2">
  <div className="rounded-card border border-neutral-200 p-4 dark:border-neutral-700">
    <p className="text-label font-semibold text-neutral-900 dark:text-neutral-100">Do</p>
    <ul className="mt-2 space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
      <li>reserve the <code>error</code> toast for something the recruiter must act on — it takes <code>role="alert"</code> and interrupts a screen reader;</li>
      <li>say what a confirmation will and will not do: “Nothing is sent to them until you send the rejection yourself.”;</li>
      <li>pair a badge's colour with its word, so the state survives a greyscale print of the pipeline;</li>
      <li>give a modal a title, or an <code>ariaLabel</code> when the design has no visible one.</li>
    </ul>
  </div>
  <div className="rounded-card border border-neutral-200 p-4 dark:border-neutral-700">
    <p className="text-label font-semibold text-neutral-900 dark:text-neutral-100">Do not</p>
    <ul className="mt-2 space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
      <li>put an action a recruiter needs inside a toast — it disappears;</li>
      <li>use a modal for information; if there is nothing to decide, it is a panel;</li>
      <li>stack modals. The <code>inert</code> and scroll-lock handling covers one dialog at a time, by design;</li>
      <li>mark a state <code>ai</code> unless a model produced it. That badge is a provenance claim.</li>
    </ul>
  </div>
</div>

<h2 className="mt-10 mb-3 text-title font-semibold text-neutral-900 dark:text-neutral-50">Anatomy</h2>

<ul className="mt-4 max-w-2xl space-y-1.5 text-label text-neutral-600 dark:text-neutral-300">
  <li><strong className="text-neutral-900 dark:text-neutral-100">Toast</strong> — a live region: <code>role="alert"</code> for errors, <code>role="status"</code> otherwise, so the rest is announced without cutting off the current sentence.</li>
  <li><strong className="text-neutral-900 dark:text-neutral-100">Modal</strong> — a portal, focus trapped and restored on close, Escape and overlay dismiss, the page behind marked <code>inert</code>.</li>
  <li><strong className="text-neutral-900 dark:text-neutral-100">Badge</strong> — never wraps: a status is one atom, and a wrapped badge clips in a table cell.</li>
</ul>
